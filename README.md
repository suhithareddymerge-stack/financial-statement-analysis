# Financial Statement Analysis

## Project Overview

This project analyses the financial performance and financial position of a London Stock Exchange listed company using four years of financial statements.

The project includes:

- Financial statement reformulation
- Profitability analysis
- Liquidity analysis
- Efficiency analysis
- Solvency analysis
- Ratio analysis
- Trend analysis
- Business valuation
- Final investment and business performance assessment

## Tools Used

- Microsoft Excel
- Financial statement analysis
- Ratio analysis
- Data visualisation

## Company

Company: To be selected

Stock Exchange: London Stock Exchange (LSE)

Analysis Period: Four years

## Project Objectives

The main objectives of this project are to:

1. Reformulate the company's financial statements.
2. Analyse the company's financial performance.
3. Calculate and interpret key financial ratios.
4. Identify trends in the company's financial position.
5. Compare the company's performance with its competitors.
6. Conduct a business valuation.
7. Provide a final assessment based on the analysis.
